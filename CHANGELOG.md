# XDuck — история версий / version history

(на русском, как вёл автор / in Russian, the author's own log)

```text
XDuck — история версий
Версия видна внизу справа на картинке в Effect Manager (XDuck.png). На экран педали версия не выводится.
Перед установкой новой версии удаляй старый XDuck в Effect Manager (номер эффекта 501, до 1.16 был 486).
XDuck.png кладётся рядом с XDuck.ZDL — это превью для Effect Manager.

1.19  (ТЕСТ)
      - Окошко сдвинуто вправо (x=14, как у заводских) — при x=0 его закрывала
        плашка «слева есть ещё эффект».
      - Вместо стрелки — значок режима Type: уточка = Duck, «П»-импульс = Gate,
        волны = Tex. На стр.2 (Thresh) и стр.3 (Attack) окошко показывает
        те же значки по положению этих ручек — так устроена педаль.
      - Звук как в 1.18.

1.18  (ТЕСТ, ставить вместе с sForm 0.14)
      - Route sForm / sFPan, тип Gate переделан: никаких атак, холдов, релизов и
        сглаживания — гейт считается заново на каждом сэмпле, поэтому работает
        на любой частоте и идёт по форме волны.
          Thresh — уровень волны, где гейт открывается: 30 = середина волны,
                   меньше — открыт дольше, больше — короче.
          Ratio  — крутизна: 0 = громкость просто идёт по волне,
                   100 = резкое вкл/выкл.
          Range  — насколько глубоко закрывается.
      - Duck и Tex без изменений (действует только Range).

1.17  (ТЕСТ, ставить вместе с sForm 0.13)
      - Route = sForm, тип Gate: теперь работают Thresh, Range и Ratio.
        Уровень волны sForm считается ключом (вершина волны = 0 дБ):
        Thresh — где гейт открывается (6 = на середине волны, 40 = почти всегда открыт),
        Ratio — жёсткость (100 = резкое вкл/выкл, меньше = плавнее, около 22 = гейт
        просто повторяет волну). Раньше гейт был только вкл/выкл на середине волны,
        поэтому синус и треугольник звучали как квадрат.
        Duck и Tex как в 1.16 (только Range).
      - Новый Route = sFPan: как sForm, но правый выход идёт по волне, сдвинутой
        на 180° — автопанорама. Есть только в режимах, где L идёт на оба выхода.
      - Route теперь: X, R>L, R<L, KeyR, KeyL, sForm, sFPan.

1.16  (ТЕСТ, основа 1.15 со стрелкой)
      - НОВЫЙ НОМЕР ЭФФЕКТА 501 (был 486 — совпадал с эффектом matujuice).
        Категория теперь Dynamics (была Delay). Старый номер 486 Effect Manager
        считает другим эффектом: удали старую версию вручную; в сохранённых
        патчах эффект придётся поставить заново.
      - Новый Route = sForm. Ставь sForm прямо перед XDuck, у sForm Out = Link.
        Громкость L следует волне sForm точно, каждый сэмпл:
          Duck — чем выше волна, тем тише (1 - LFO)
          Gate — открыт, пока волна в верхней половине (переход 0.5 мс без щелчка)
          Tex  — громкость = волна
        Глубина — Range (60 = почти до тишины). Thresh, Ratio, Attack, Hold,
        Release и Freq в этом режиме не действуют.
        На оба выхода идёт обработанный L.

1.15  (ТЕСТ, файлы XDuck.ZDL + XDuck.png)
      - Своя картинка крутилки: вращающаяся стрелка без квадратной рамки
        (формат "style 12", как у заводских GrayComp / TapeEcho3).
        Стрелка поворачивается вместе с ручкой: от 7 часов (минимум) до 5 часов (максимум).
      - По-прежнему одно окошко внизу слева. Звук и ручки как в 1.13.
      - Если педаль не примет: вернуть 1.14 или 1.13 (backup_1.13).

1.14  (ТЕСТ — на педали работает: одно окошко, остальное как раньше)
      - Эксперимент: вместо трёх окошек значений одно, внизу слева. На 1-й странице оно
        показывает режим (Duck / Gate / Tex). Под убранными окошками вернулась картинка.
      - Такой вариант (9 ручек, 1 окошко) не встречается ни в одном заводском эффекте,
        прошивка может его не принять. Запасная 1.13 лежит в папке backup_1.13.
      - Звук и ручки как в 1.13.

1.13  (релиз на GitHub, копия в backup_1.13)
      - Тип Tex проверен на педали — работает.
      - Та же картинка, что в 1.12, но утка не сжата: надпись на месте, утка
        и черточки сдвинуты на 8 пикселей вправо (кончики правых черточек
        уходят за край экрана).
      - Звук и ручки как в 1.08.

1.12
      - Картинка по третьему эскизу ("Крутая пиксельная утка XDUCK"): полая комиксовая
        надпись по дуге, утка в очках, по три черточки с каждой стороны.
        Надпись 1:1 на своём месте; утка с черточками чуть сжата по ширине, чтобы
        окошки значений не закрывали лапу.
      - Превью Effect Manager по тому же эскизу.
      - Звук и ручки как в 1.08.

1.11
      - Надпись XDuck шрифтом из первой картинки (заглавные X и D, строчные uck),
        по диагонали в левом верхнем углу. Утка, хвост и черточки из второго эскиза.
      - Убран шум под "c" и под/правее "k".
      - Звук и ручки как в 1.08.

1.10
      - Новая картинка по второму эскизу: полая надпись XDUCK по диагонали в левом
        верхнем углу, утка в очках с хвостом, черточки вокруг утки. Весь экран целиком.
      - Подписей и крутилок на экране нет: окошки значений (внизу слева, вплотную
        друг к другу) сами показывают Duck / KeyR / 60 и т.п.
      - Превью Effect Manager тоже по новому эскизу.
      - Звук и ручки как в 1.08.

1.09
      - Надпись XDuck крупнее и по диагонали снизу вверх в левом верхнем углу,
        контур X целиком, мусор под "c" и "k" убран.
      - У утки вернулся чубчик и две нижние черточки движения слева.
      - Звук и ручки как в 1.08.

1.08
      - Route: X, R>L, R<L, KeyR, KeyL.
        R>L  — правый управляет левым, правый проходит как есть.
        R<L  — левый управляет правым, левый проходит как есть.
        KeyR — правый управляет левым, правый на выход не идёт (только ключ).
        KeyL — левый управляет правым, левый на выход не идёт (только ключ).
      - Картинка на педали пересобрана чище: LCD-текстура эскиза сглажена перед
        уменьшением, убраны штрих под "uc" и мусор по краям утки.

1.07
      - Texture теперь ТИП (Type = Tex), а не маршрут. Громкость обрабатываемого сигнала
        плавно следует за громкостью управляющего: чем громче один, тем громче другой
        (как однополосный вокодер; с Freq выбираешь полосу). Оба сигнала смешиваются
        и идут одинаково в оба выхода.
        Thresh = уровень ключа, при котором обрабатываемый сигнал звучит в полную силу;
        Ratio 100 = следует децибел в децибел; Range = насколько глубоко может уйти.
      - Route снова три значения: X, R>L, Key (TexL/TexR из 1.06 убраны).
      - Окошки значений ручек снова в горизонтальный ряд (внизу слева), как у всех
        заводских эффектов: столбик справа в 1.06 давал лишнюю полосу на экране.
      - Надпись XDuck теперь целиком (k больше не обрезана), утка справа.
      - Превью Effect Manager: убраны полоски-индикаторы "1/2" сверху справа.

1.06
      - Новые режимы Route: TexL и TexR (texture). Один сигнал гейтится/дакается другим,
        и ОБА сигнала идут в оба выхода (левый и правый одинаковые).
        TexL: правый вход управляет левым. TexR: левый вход управляет правым.
      - Порядок ручек: главные теперь на 1-й странице.
        Стр.1: Type, Route, Freq | Стр.2: Thrsh, Range, Ratio | Стр.3: Attk, Hold, Rels
      - Обложка на педали: надпись XDuck и утка из эскиза, без нарисованных крутилок и без версии.
        Окошки значений столбиком справа, рядом подписи стр.1 (TYPE, ROUTE, FREQ).
      - Превью для Effect Manager (XDuck.png): весь эскиз целиком + версия внизу.

1.05
      - Новая ручка Freq (9-я, стр. 3): на какой частоте слушать ключ.
        Full = вся полоса; 40, 60, 100 ... 8k Гц = полосовой фильтр вокруг этой частоты.
        Фильтр влияет только на срабатывание Duck/Gate, сам звук не фильтруется.
      - Обложка по картинке-образцу: утка в очках слева во всю высоту,
        XDUCK и версия сверху, окошки трёх ручек столбиком справа.
      - Ручки (9): Thrsh, Range, Ratio | Attk, Hold, Rels | Type, Route, Freq

1.04
      - Новая обложка: утка на воде, крупное название XDUCK, версия под ним.
      - Названия ручек на экране сокращены до 5 букв, чтобы не налезали друг на друга:
        Thrsh, Range, Ratio | Attk, Hold, Rels | Type, Route
      - Звук не менялся.

1.03
      - Route = Key: левый канал идёт только в левый выход, правый выход молчит.
      - Ручки (8): Thresh, Range, Ratio | Attack, Hold, Release | Type, Route

1.02
      - Убрана ручка KeyIn: на "сыром" входе педали правого канала нет (тест XProbe).
        Чтобы ключ был чистым, ставь XDuck первым в патче.
      - Добавлена ручка Hold (0-500 мс): держит реакцию после удара, убирает дребезг гейта.
      - Порог по умолчанию -40 дБ.
      - Route = Key: левый канал шёл в оба выхода (исправлено в 1.03).

1.01
      - Убрана ручка Mix (всегда 100%). 8 ручек, ещё с KeyIn.

1.00
      - Первая версия: 9 ручек, Mix, KeyIn (Chain/Raw).
```
